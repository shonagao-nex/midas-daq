Manual Event Buffer Clear

Available only while MIDAS is STOPPED. This discards buffered event data; it does not reset module configuration.

MOCK PREVIEWNo MIDAS or hardware access is performed.
Before clearing: stop external triggers when practical. Cleared event data cannot be recovered.

VME event buffers
